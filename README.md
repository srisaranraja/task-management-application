# Task Management Application

A full-stack Task Management Application built using Java and Spring Boot.

## Live Demo

https://task-management-application-3-boop.onrender.com

## Features

- Create new tasks
- View all tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks
- Store task data in MySQL database

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Aiven Cloud Database
- Render
